Robot Motion Studio（PCアプリ）の使い方
========================================

■ 動作確認の範囲
  Windows 11（64bit）向けです。Windows 10 でもたぶん動きますが、確認していません。
  Linux・Mac は対象外です。

■ 必要なもの
  ・Bluetooth（BLE）が使える PC
      PC に Bluetooth が無い場合は、BLE に対応した USB の Bluetooth アダプタを挿してください。
  ・Microsoft Edge または Google Chrome（Windows 11 には Edge が最初から入っています）
  ・Python 3.12（Python 3.10〜3.12 でも動く場合があります。setup.bat が Python を探します）

■ はじめに：zip は必ず「展開」してから使う
  zip をダブルクリックして中のファイルを直接実行すると、正しく動きません。
  zip を右クリック →「すべて展開」→ 展開してできたフォルダを開いてから、起動してください。
  （デスクトップやドキュメントなど、自分のフォルダに置いてください。Program Files の中は避けてください）

■ 起動のしかた
  1. Python 3.12 を https://www.python.org/downloads/ から入れます。
     インストール画面の最初で「Add python.exe to PATH」にチェックを入れてから「Install Now」を押します。
  2. 初めて使う PC では、setup.bat をダブルクリックします。
     必要な部品をダウンロードして .venv フォルダを作ります（数分かかります。インターネット接続が必要です）。
     ※ run.bat を最初に実行しても、同じ準備が自動で行われます。
  3. run.bat をダブルクリックします。専用のウィンドウが開きます。

  ・ウィンドウを閉じると、アプリも終了します（ロボットとの Bluetooth 接続も切ります）。
  ・すでに起動しているときにもう一度起動すると、同じアプリのウィンドウがもう1つ開きます（2つ目のアプリは動きません）。

■「WindowsによってPCが保護されました」と出たとき（SmartScreen）
  ダウンロードしたファイルなので表示されることがあります。
  「詳細情報」を押す →「実行」を押すと起動できます。

■ Bluetooth について
  ・Windows の「設定 → Bluetooth とデバイス」で Bluetooth をオンにしてください。
  ・ロボットの電源を入れ、PC の近くに置いてから「接続」を押してください。
  ・ロボットを Windows の「デバイスの追加」でペアリングする必要はありません。
  ・つながらないときは、ログ欄にエラーの原因の候補が表示されます。

■ 保存について
  ・モーションの「保存」「読込」「エクスポート」では、保存先を選ぶ画面が出ます（ブラウザの機能を使っています）。
  ・前回の保存先を覚えていて、次回はそこから開きます。
  ・「統合（別の JSON を追加）」で、別のモーション JSON を今のモーションに追加できます。
      同じ名前で中身も同じ → 1件にまとめます。
      同じ名前で中身が違う → 「今のものを残す」「取り込みで置き換える」「別名で両方残す」から選びます。
        「残りの違うモーションにも同じ操作を使う」にチェックを入れると、以降は聞きません。
      途中で「中止」を押すと、何も変わりません。統合後は Ctrl+Z で元に戻せます。
  ・エクスポートで ExportData.h を上書きしたときは、上書き前の内容を「backup\ExportData.h.bak」に1つだけ残します
    （保存先フォルダではなく、下の「設定とログの場所」の中です）。

■ 設定とログの場所
  ・基本はこのフォルダ（run.bat と同じ場所）です。
      settings.json ............ 設定
      pose_library.json ........ ポーズライブラリ
      robot_motion_studio.log .. ログ（困ったときはこのファイルを送ってください）
      backup\ .................. エクスポートで上書きする前の内容
      browser_profile\ ......... 専用ウィンドウ用のデータ
  ・このフォルダに書き込めない場合は、自動で %APPDATA%\RobotMotionStudio に保存します。
  ・アプリのログ欄の「ログの場所を開く」で、保存先のフォルダを開けます。
  ・ユーザー名に日本語が入っている PC では、専用ウィンドウ用のデータだけ
    C:\ProgramData\RobotMotionStudio（または C:\Users\Public\RobotMotionStudio）に置きます。

■ うまく動かないとき
  ・ウィンドウが開かない：Edge か Chrome が入っているか確認してください。どちらも無い場合は、
    いつものブラウザで開きます（その場合、保存の画面がダウンロードになることがあります）。
  ・「PCアプリとの接続が切れました」と出た：アプリが終了しています。ウィンドウを閉じて起動し直してください。
  ・それでもだめなとき：robot_motion_studio.log を添えて連絡してください。
